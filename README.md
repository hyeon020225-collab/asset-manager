# 내일의 자산 — 청년 자산 형성 웹서비스

청년이 자신의 **생활 유지 비용·부채·비상자금·단기 자금**을 먼저 파악하고, 남은 여력으로 감당 가능한 포트폴리오와 **10,000회 시간 여행 시뮬레이션**을 무료·무제한으로 체험할 수 있는 금융교육 웹 애플리케이션입니다.

---

## 1. 설치 및 실행 방법

```bash
# 의존성 설치
npm install

# 개발 서버 실행 (Express + Vite, http://localhost:3000)
npm run dev

# 단위 테스트 실행 (Vitest)
npm test

# 타입 검사 및 프로덕션 빌드
npm run lint
npm run build

# 프로덕션 서버 실행
npm start
```

> **API 키 없는 환경 지원**: `.env`에 `GEMINI_API_KEY`가 설정되지 않아도 전체 핵심 흐름(현금흐름 분석, 성향 평가, 4개 투자자 스타일 배분, 10,000회 Web Worker 시뮬레이션, 규칙 기반 자연어 추출/해설)이 100% 작동합니다.

---

## 2. 완성된 주요 기능

1. **내 돈 파악 & 투자 가능 금액 산출 (`src/engine/cashflow.ts`)**
   - 세후 월소득, 소득 안정성, 필수·선택·연간 비정기 지출, 부채 목록(필수지출 포함 여부 체크로 중복 차감 방지), 사용 불가 자산(전세보증금·주택) 제외, 비상자금 목표 개월 수, 단기 예정 지출 보호.
   - 적자 또는 비상자금 부족 시 추천 월 투자액을 0원으로 보수 산정하고 지출 조정·비상자금 확보·부채 상환 시나리오를 비교합니다.
2. **성향 + 재무 여건 분리 평가 및 투자자 스타일 (`src/engine/portfolio.ts`, `src/data/instruments.ts`)**
   - 심리적 위험 선호(반응·경험·변동성 의사)와 객관적 손실 감당 능력을 별도 점수화하고, 손실 감당 예산 초과 확률을 계산합니다.
   - `기본 분산형`, `워런 버핏 원칙 참고형`, `피터 린치 원칙 참고형`, `스탠리 드러켄밀러 원칙 참고형`(t-1 직전 추세 신호 기반 단순화 모형, 차입·공매도 제외) 제공.
   - 가운데 빈 도넛 차트(자산군/개별종목 전환, 비중 합계 100.0%, 0원 빈 상태), 비중 직접 수정, 참고 상품 메타데이터(보수, 통화, 환헤지, 공식 출처, 중복 노출 경고) 포함.
3. **10,000회 시간 여행 시뮬레이션 (`src/engine/simulator.ts`, `src/workers/simulation.worker.ts`)**
   - **A. 모수 기반 몬테카를로** (Cholesky 상관관계 보정, 다변량 로그정규, 원화 환산 `(1+r)(1+f)-1`) 및 **B. 과거 자료 블록 부트스트랩** 지원.
   - 입출금을 보정한 **단위 기준가(TWR)** 및 **도중 최대낙폭** 계산, 잔액 초과 인출 시 음수 없이 자금 부족 횟수 기록, 명목 vs 물가반영 현재가치 전환, 1년/10년/은퇴 시점 비교 및 시나리오 A/B 스냅샷 비교.
4. **데이터 검증 · CSV 가져오기 · AI 도우미 (`src/engine/backtest.ts`, `server.ts`)**
   - CSV 파싱(날짜·단위·결측·중복·관측 기간 검사), 순차 Out-of-Sample Walk-Forward 백테스트.
   - 선택적 서버측 Gemini AI(`gemini-4-hydrogen`) 연동 시 전송 JSON 범위 사전 확인 및 미연동 시 규칙 기반 설명 명시.
5. **주사위(1회) & 10,000회 간편 GBM 시뮬레이터 · URL 공유 (`src/engine/gbmQuickSim.ts`, `src/components/QuickGbmSimulatorView.tsx`)**
   - 기본 100만 원 및 빠른 금액 버튼, 보수형(4%/6%)·중립형(7%/13%)·위험감수형(10.5%/22%) 가정 수정 슬라이더, 4개 기간(1개월/6개월/1년/10년) 지원.
   - 브라우저 JS Box-Muller GBM으로 1회 무작위 경로 애니메이션과 10,000회 분포 히스토그램·백분위(상위 N%)를 실시간 비교하고, 상단 `설정 링크 복사`로 파라미터 URL을 공유할 수 있습니다.

## 3. 데이터 연동 및 알려진 한계

- 본 저장소의 기본 자산군 가정 및 180개월 샘플 시계열(`src/data/historicalSample.ts`)은 **개발·교육용 샘플**이며 실시간 거래소 시세가 아닙니다.
- 상품 카드에 기재된 보수·티커는 공시 문서 참고 정보이며, 실시간 호가나 세금(양도소득세·배당소득세·ISA/연금계좌 과세이연)은 반영되지 않은 **세전 기준**입니다.
- 향후 본 서비스를 실제 상용 서비스로 확장할 경우, 개인별 금융상품 추천 및 투자자문/유사투자자문 요건은 금융위원회 안내 등 **최신 국내 법령과 실제 서비스 제공 방식에 맞춰 별도의 법률·규제 검토**가 반드시 필요합니다. (‘교육용’이라는 명칭만으로 관련 규제 요건이 자동 면제되지 않습니다.)
